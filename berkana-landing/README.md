# Berkana — лендинг «Аренда специальной техники»

Тестовое задание: вёрстка одностраничного сайта-лендинга для компании,
занимающейся арендой спецтехники (экскаваторы-погрузчики, самосвалы и т.д.).

🔗 **Демо:** добавьте сюда ссылку на GitHub Pages после публикации
(Settings → Pages → Branch: main → / (root))

## Стек

- HTML5
- CSS3 (кастомные стили, без препроцессоров)
- [Bootstrap 5](https://getbootstrap.com/) — сетка, компоненты, карусель
- [Bootstrap Icons](https://icons.getbootstrap.com/)
- Шрифт Manrope (локально, woff2)

## Реализовано

- Шапка сайта с контактной информацией и адаптивным меню
- Hero-секция с каруселью (Bootstrap Carousel)
- Блок «Популярная спецтехника» с карточками товаров и слайдером
- Полностью адаптивная вёрстка (Bootstrap grid + брейкпоинты)
- Все зависимости подключены локально, без CDN

## Структура проекта

```
berkana-landing/
├── index.html
└── assets/
    ├── css/          # кастомные стили
    ├── fonts/         # шрифт Manrope (woff2)
    ├── img/           # изображения
    └── vendor/        # Bootstrap и Bootstrap Icons
```

## Запуск

Проект статичный, сборка не требуется — достаточно открыть `index.html`
в браузере или поднять локальный сервер, например:

```bash
npx serve .
```
